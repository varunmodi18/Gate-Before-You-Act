GLOBAL STYLE PROMPT (give this first)
Create a clean, technical presentation deck for an academic course project. Use a white
background, one dark text colour and a single accent colour (deep blue). Use green only for
"supported" or "good" and red only for "not met" or "bad". Give each capability one fixed
colour, used everywhere: Tool calling = purple, RAG = orange, Reasoning = blue, Agentic =
teal. One idea per slide, a short title that states the takeaway, at most 4 bullets of no
more than 12 words each. Show the main number in large type when a slide is about one number.
No stock photos or clip art; diagrams and the provided charts only. Mark course-activity
slides with a small grey tag "Course activity" in the top-right corner.

SLIDE 7: ARCHITECTURE
======================================================================
Title: "GateBench: every state-changing action passes the gate"
Visual: clean diagram. Logs (untrusted, red dashed) -> Investigate -> Findings -> Propose
(action + cited record IDs) -> Pre-action gate -> Execute / Escalate or gather more / Block.
Trusted context (green) feeds Propose and the Gate. Retrieval index (Sigma + ATT&CK) feeds
the Gate. Gate lists C1 allow-list + provenance, C2 citation scope, C3 target match (code),
C4 LLM verifier, C5 policy (9 rules), C6 approval.
Put small capability badges on the diagram: TOOL CALLING on the tools, RAG on the index,
REASONING on C4, AGENTIC on the "gather more" loop.

SLIDE 8: [ACTIVITY] ONE TOOL'S SCHEMA
======================================================================
Title: "Tool design: kill_process"
Show as a schema card in monospace:
name: kill_process (one process on one host)
use when: a cited record shows this PID itself doing the malicious activity on this host
don't use: for the parent, the access target (lsass.exe), system processes, or account-only
evidence; escalate instead
host: string, hostname pattern, must be in the asset inventory. Likely wrong: an IP, or a
name from an attacker's command line
pid: integer > 0 (strict), must appear in a retrieved record. Likely wrong: "5172" as a
string, the access mask 0x1438, the parent's PID
Error strings (monospace, red):
C1_SCHEMA: Arguments for kill_process are invalid.
C1_UNPROVENANCED_VALUE: PID 7924 does not appear as a PID in any record you have retrieved.
