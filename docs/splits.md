## Notes

- `collection` has a single eligible window; its proportional quota rounds to 0 in every split, so the tactic is in no split. To be listed in the final report's limitations.
- SDWIN-230718150800 ("Dumping NTDS.dit from Volume Shadow Copy") is excluded: its Host file `cmd_copy_ntds_from_volume_shadow_copy.zip` does not exist at the pinned commit; a similarly named file is deliberately not substituted. 99 of the 100 windows were ingested.
- De-duplication pairs (J > 0.5) are different attacks recorded in the same lab sessions; shared background events push their similarity over 0.5. Grouping only keeps each pair in the same split (the cautious side).
- The LSASS demo window (SDWIN-201018225619) is `unused`, so the demo fixture does not reuse a research window.
